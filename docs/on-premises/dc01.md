# TW-DC01

## Overview

TW-DC01 is the primary Domain Controller of the on-premises infrastructure.

The server provides the core identity and network services required by the local environment.

## System Information

| Parameter        | Value                     |
| ---------------- | ------------------------- |
| Hostname         | TW-DC01                   |
| Operating System | Windows Server 2025       |
| Domain           | techwork.local            |
| IP Address       | 10.0.0.5                  |
| Role             | Primary Domain Controller |

## Implemented Services

### Active Directory Domain Services

Active Directory Domain Services (AD DS) is installed on TW-DC01.

The server hosts the primary domain:

`techwork.local`

### DNS

DNS is installed and integrated with Active Directory.

TW-DC01 currently provides internal DNS resolution for the on-premises domain.

### DHCP

DHCP is configured for the local network and provides IP configuration to clients.
