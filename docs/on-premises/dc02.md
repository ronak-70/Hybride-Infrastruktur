# TW-DC02 — Secondary Domain Controller

## Overview

TW-DC02 is the secondary Domain Controller of the `techwork.local` domain.

Its purpose is to provide redundancy for Active Directory and DNS and to support the High Availability design of the on-premises infrastructure.

## Configuration

| Property   | Value                       |
| ---------- | --------------------------- |
| Hostname   | TW-DC02                     |
| Domain     | techwork.local              |
| IP Address | 10.0.0.6                    |
| Role       | Secondary Domain Controller |
| Services   | AD DS, DNS                  |

## Domain Controller Installation

TW-DC02 was added to the existing `techwork.local` domain using:

> Add a domain controller to an existing domain

The server was promoted successfully and Active Directory replication was configured.

## Purpose

TW-DC02 provides redundancy for:

- Active Directory
- DNS
- Domain authentication
- Domain Controller availability

## High Availability

TW-DC02 will later be used to test the availability of the domain environment during a controlled failure of TW-DC01.

Planned test:

1. Verify normal domain operation.
2. Shut down TW-DC01.
3. Test DNS resolution.
4. Test domain functionality from TW-CLIENT.
5. Verify that TW-DC02 remains available.
6. Start TW-DC01 again.
7. Verify Active Directory replication.

## Validation

The following commands can be used for validation:

```powershell
ipconfig /all
nslookup techwork.local
dcdiag
repadmin /replsummary
```
